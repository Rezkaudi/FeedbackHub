## How to write a decision

Give each one a number (D-01, D-02, ...) and write four short parts:

- **Context** — what was the problem.
- **Options** — what else we could have used.
- **Decision** — what we picked.
- **Consequences** — what is good about it, and what is bad about it.

Rules:

- Always write the other options. Never act like there was only one answer.
- Always write the bad side too. Every choice has one.
- If a decision changes later, add a new one. Do not delete the old one.

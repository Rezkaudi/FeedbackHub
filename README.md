# FeedbackHub

An internal feedback board.

People at the company write feature requests and feedback. Everyone can read
them, vote for the ones they like, and talk about them in comments. An admin
sets the status of a request, manages the categories, and moderates the
content.

The goal: stop the same idea coming five times by email, and show what is
really being worked on.

**Status: nothing is built yet.** Only the documents exist.
